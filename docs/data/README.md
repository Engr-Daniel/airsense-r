# Explorer data

Generated by `python scripts/build_explorer_data.py`; do not edit by hand.

- `explorer.json`: compact summaries of the accepted clean benchmark (P5), sensor stress and
  unseen-station evidence (P8 snapshot), the post-results PM2.5 target-history extension (P9),
  exploratory failure diagnostics, and provenance (result commits, receipt/manifest hashes).
- `clean-prediction-windows.json`: observed and predicted clean-test PM2.5 for four fixed
  calendar weeks per station; learned models keep each training seed separate.

Every input is read from accepted result commits and checked against acceptance receipts and
manifest checksums. Nothing here is fitted or inferred. `p6-runs/` holds older fixture exports
that the explorer does not use.
